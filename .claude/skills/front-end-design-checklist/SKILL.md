# Front-End Design Checklist

A comprehensive checklist of the elements web designers and front-end
developers should consider when building and reviewing a web page. Use it
to audit a page's design and front-end quality, or as a pre-launch gate.

## How to use

1. Read `checklist.md` in this skill directory — it is the full checklist,
   organized by section (Design requirements, Typography, Colors, Images &
   Icons, Interactions/animation, Accessibility, Performance, SEO, and more).
2. Walk the relevant sections against the page or design in question.
3. For each item, report: pass / fail / not-applicable, with a concrete fix
   where it fails. Prioritize accessibility, performance, and responsive
   correctness.

The `images/` directory holds illustrative examples referenced by the
checklist.
