# Awesome Design MD

A library of brand design systems, each written as a `DESIGN.md` that an
agent can read and apply directly. Each entry lives in
`design-md/<brand>/DESIGN.md` (with a short `README.md` alongside).

## How to use

1. Pick the brand whose aesthetic matches the goal (see the index below),
   or ask the user which brand/feel they want.
2. Read `design-md/<brand>/DESIGN.md` for that brand's tokens and rules
   (palette, typography, spacing, components, motion, voice).
3. Apply those rules to the page/component being built. Treat the file as a
   design spec, not as copy to paste — adapt tokens to the project's stack.

Do NOT reproduce a brand's logo, trademarks, or proprietary assets, and do
not pass a product off as that brand. These are references for art
direction and system structure.
